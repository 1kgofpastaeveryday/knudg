Knudg development has stopped.

Knudg was a self-hostable worklog for coding agents: it kept which fix worked, which paths failed, and which environment traps wasted the run, so the next attempt could start from what was already learned.

It is no longer being developed. No new releases, fixes, or support are planned.

The source code is available on GitHub under the Apache-2.0 license, as is.
